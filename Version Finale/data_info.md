# Dataset utilisé : Diabetes de Scikit-Learn

- Source : module `sklearn.datasets`, fonction `load_diabetes(as_frame=True)`
- Référence : https://scikit-learn.org/stable/datasets/toy_dataset.html#diabetes-dataset
- Format : 442 patients, 10 variables continues normalisées + target continue (score de progression du diabète)
- Chargement : les données sont téléchargées et intégrées automatiquement par Scikit-Learn, aucun fichier CSV local n’est nécessaire.
