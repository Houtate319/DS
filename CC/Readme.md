# Prédiction des prix immobiliers par régression supervisée

## 📊 Aperçu du projet

Ce projet explore **l'analyse prédictive des prix de maisons** aux États-Unis à partir d'un jeu de données immobilier contenant plus de 20 000 districts en Californie. L'objectif est de comparer plusieurs modèles de **régression supervisée** pour identifier le plus performant et comprendre les variables déterminantes du prix des maisons.

---

## 🎯 Objectifs

- Construire et entraîner plusieurs modèles de régression supervisée
- Comparer leurs performances à l'aide de métriques standardisées (RMSE, R²)
- Identifier les variables les plus influentes dans la prédiction du prix
- Fournir un modèle fiable pour estimer le prix médian des maisons
